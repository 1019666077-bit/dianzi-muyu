# 电子木鱼 · 日日用与收益提升方案（执行版）

> 依据：[`tools/DAILY-USE-REVENUE-RESEARCH.md`](./DAILY-USE-REVENUE-RESEARCH.md)  
> 对象：`mp-weixin/` 微信小程序（木鱼 / 念珠 / 颂钵，本地功德，激励视频换快敲与皮肤）  
> 用途：供你审阅后再排期开发；**本文不改代码**。  
> 日期：2026-09-16

---

## 1. 我们要解决什么问题

| 问题 | 现状（代码/运营） | 目标 |
| --- | --- | --- |
| 用户第二天还来吗 | 有今日/昨日/总，但**首页只显示总功德**；无连续天数；分享标题固定「电子木鱼」 | 让用户感到「今天还没敲够 / 连续还在」，并愿意从任务栏、分享、搜一搜回来 |
| 能赚钱吗 | `REWARDED_AD_UNIT_ID` 为空；UV 未过 500 则流量主为 0 | 合规开通流量主后，**自愿激励**成为主收入，不牺牲敲击体验 |
| 会不会审不过 | 宗教话术、诱导分享、过度广告是红线 | 全程 **解压玩具** 定位，广告用户自己点 |

**不采用的 KPI（报告已说明口径错误）**

- 微信小游戏「14 日留存 50%」——我们是普通小程序，不是小游戏大盘。  
- 2022 年 App 下载 500 万——品类与渠道都不等于本小程序。  
- 联盟文里的「激励 eCPM 15–200 元」——官方无公开区间，**只以后台 eCPM 为准**。

**建议自设 KPI（上线后用微信后台 + 本地调试页）**

| 指标 | 含义 | 早期参考（来自 GameAnalytics 中位，偏保守） |
| --- | --- | --- |
| 次日回访率 | 昨日有访问的用户今日是否再开 | 休闲点击类 D7 中位约 **4%** 量级；D1 可盯 **20%+** 为努力方向，非承诺 |
| 7 日打开天数 | 安装后 7 天内打开过几天 | streak 功能直接服务此指标 |
| 人均激励完播 / 日 | `isEnded` 成功次数 / 访问人数 | 产品规则上限 **1–2 次快敲领奖/日**（防疲劳，非微信官方数） |
| 场景 1089 / 1036 / 1053 占比 | 任务栏 / 分享 / 搜一搜 | P0 改分享与任务栏引导后 4 周对比 |

## 2. 产品原则（所有需求都过这四条）

1. **Fogg 行为 = 动机 × 能力 × 提示**：敲一下能力已够；补动机（今日缺口、streak）和提示（任务栏、可选订阅）。  
2. **Lally 2010**：习惯靠**同一情境重复**；中位约 **66 天**；**漏一天**对曲线影响不大 → streak 可设计 1 次「补签/冻结」本地逻辑。  
3. **激励必须自愿**（微信文档 + Unity 相关研究）：只保留「视频·快敲 / 视频·皮肤」按钮触发；快敲结束**不立刻**弹第二支视频。  
4. **合规**：不用「开光、消业、往生、法事」；不选宗教类目；不做「不分享不能玩」。

## 4. P0-A · 习惯可见 + 分享（开发，约 3–5 人天）

**目标**：不动隐私声明、不上服务器，让用户**每天**有理由再看一眼数据页或顶栏。

### 4.1 顶栏功德：总 + 今日（双行或主次）

| 项 | 说明 |
| --- | --- |
| 改什么 | `pages/index/index.wxml` 的 `.merit-pill`；`syncMeritUI()` 增加 `todayMerit` |
| 展示 | 主数字：**今日** `todayMerit`；副文案：`总 {{total}}` 或单行「今日 n · 总 m」 |
| 依据 | 报告 §2「今日功德缺口」；竞品数据页有四行，但首页只露「总」不够促回 |
| 验收 | 敲 3 下 → 顶栏今日 +3；跨日 rollover 后今日归零、昨日正确 |

### 4.2 数据页：昨日对比 + 一句缺口文案

| 项 | 说明 |
| --- | --- |
| 改什么 | `pages/stats/stats.wxml` / `stats.js` |
| 逻辑 | 若 `yesterdayMerit > 0` 且 `todayMerit < yesterdayMerit`：展示「距昨日还差 {{yesterdayMerit - todayMerit}}」；若今日已超昨日：「已超昨日 +N」 |
| 文案禁区 | 不用「还愿」「祈福成功」；用「解压记录」「敲击次数」 |
| 验收 | 手动改 storage 或跨日模拟 rollover 后文案正确 |

### 4.3 本地连续天数（streak）—— schema 小扩展

| 项 | 说明 |
| --- | --- |
| 改什么 | `utils/merit.js`：`schemaVersion` → 3，增加字段见下 |
| 新字段 | `streakDays`（当前连续天数）、`streakLastDate`（最后计入 streak 的本地 YYYY-MM-DD）、`streakFreezeUsed`（本自然月是否用过 1 次冻结，可选 P1 再做冻结） |
| 规则 | 当日 `todayMerit > 0` 且 `todayDate` 为今天：若 `streakLastDate` 是昨天 → `streakDays++`；若是今天 → 不变；若间隔 >1 天 → 归零（或 P1 用 freeze） |
| 展示 | 数据页顶区：「已连续 N 天」；N=0 时不强调 |
| 依据 | Duolingo streak 博客（相关非因果）；Lally 漏一天无伤 |
| 验收 | 连续 3 天有敲击 → streak=3；隔 2 天再敲 → streak=1 |

### 4.4 分享卡片（拉新 + 老用户炫耀）

| 项 | 说明 |
| --- | --- |
| 改什么 | `pages/index/index.js` → `onShareAppMessage` |
| 标题示例 | `今日敲击 {{todayMerit}} 次 · 电子木鱼`（`todayMerit` 从 `this.state` 读） |
| 路径 | 保持 `/pages/index/index` |
| 图片 | 新增 `assets/share-cover.webp`（木鱼静帧 + 品牌字，**无佛像/经文**），`imageUrl` 指向本地路径 |
| 依据 | 场景值 1036；报告 P0 分享 |
| 验收 | 开发者工具转发预览标题带数字、图不糊 |

**可选（仍 P0）**：邀请按钮旁小字「分享给好友一起解压」，不绑奖励、不强制。

### 4.5 首次功德后：「添加到我的小程序」轻引导

| 项 | 说明 |
| --- | --- |
| 改什么 | `index.js`：`bump` 后若 `total` 从 0→1 或 `todayMerit` 首次 >0，且本地 flag `hintMyMiniProgramShown` 未设，则 `wx.showModal` 一次 |
| 文案 | 「长按右上角 ··· → 添加到我的小程序，下次从下拉任务栏打开」 |
| 依据 | 场景 1089；Fogg「提示」 |
| 验收 | 仅首次出现；拒绝后不再弹 |

### 4.6 快敲结束：状态文案（不弹广告）

| 项 | 说明 |
| --- | --- |
| 改什么 | `updateAutoStatus` 快敲归零时 |
| 文案 | `status`：「今日快敲已结束 · 明天可再看视频续 5 分钟 · 慢敲仍可用」 |
| 禁止 | 倒计时结束 **0.5 秒内** 再 `showAd('auto')` |
| 依据 | 报告 §2 自动敲「明天再来」；广告疲劳 |
| 验收 | 手动把 `autoUntil` 设为过去时间或等 5 分钟结束，不出现二次激励弹窗 |

## 5. P0-B · 运营与变现准备（你本人操作，约 1–2 天）

| 步骤 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 注册 AppID、提审体验版 | 见 `LAUNCH.md` §0 |
| 2 | MP 简介 / 搜索 | 关键词：**电子木鱼、解压、点击、念珠、颂钵、静心**；**不要**占「功德木鱼」品牌词 |
| 3 | 类目 | **工具 → 效率** 或 **文娱 → 休闲**；**不要** 宗教信息 |
| 4 | 隐私指引 | 粘贴 `PRIVACY.md`；P0 阶段仍「仅本机」 |
| 5 | 盯 UV | We 分析「累计访问人数」≥ **500** 后，后台 **推广 → 流量主** 开通 |
| 6 | 个人主体 | 培训 PDF：个人可结算、代扣个税；填银行卡 |
| 7 | 填 `REWARDED_AD_UNIT_ID` | 开通后写入 `config/launch.js`；真机测完播发奖 |
| 8 | 记录 baseline | 开通前后各记 7 天：访问人数、广告 eCPM、人均曝光（后台「广告核心数据」） |

**收入预期（仍是情景，不是承诺）**

- 公式：`日收入 ≈ DAU × 人均激励完播 × eCPM / 1000`  
- 在 eCPM 未知时，**只跟踪相对变化**：改分享 / streak 后 DAU 与完播是否上升。

## 6. P1-A · 体验与广告节奏（开发，约 5–8 人天）

### 6.1 激励日上限（产品规则）

| 项 | 说明 |
| --- | --- |
| 改什么 | `index.js` + 可选 `utils/ad.js` 旁路计数 |
| 规则建议 | 每自然日：**快敲领奖**（看完视频并成功 `grantAuto`）最多 **2 次**；**皮肤解锁**最多 **3 次**（或保持现状 1 次下一档） |
| 存储 | `state.adGrantAutoCount` + `adGrantAutoDate`（本地，随 merit 存） |
| UI | 超限时 toast：「今日视频次数已够，明天再来；慢敲仍免费」 |
| 依据 | 微信「每日观看次数有限」+ 报告反证「激励过多」 |

### 6.2 右栏「自动」与底部按钮文案统一

| 项 | 说明 |
| --- | --- |
| 现状 | 右栏自动 = 慢敲 toggle；底部「视频·快敲」= 激励 |
| 优化 | 快敲进行中右栏第三钮 active；tooltip 或 status 行解释「慢敲免费 / 快敲需视频」 |
| 验收 | 与你截图参考一致，且不挡木鱼槌（`side-rail top` 必要时 62%） |

### 6.3 本地场景值统计（调试用，不上传）

| 项 | 说明 |
| --- | --- |
| 改什么 | `app.js` `onLaunch` / `onShow` 读 `wx.getLaunchOptionsSync().scene` |
| 存储 | `localStats: { scene1089, scene1036, scene1053, other, lastReportWeek }` 仅本机 |
| 页面 | 隐藏入口：数据页长按标题 5 次 → 显示本周场景占比（给运营看，不给用户） |
| 依据 | 报告 P1 场景值日志 |

### 6.4 streak 进阶（可选同 P1）

- **月内 1 次冻结**：间隔 2 天时若 `streakFreezeUsed` 为 false，消耗冻结保持 streak（对应 Lally「漏一天」）。  
- **7 日轻庆祝**：streak 到 7 时浮字「连续 7 天」+ 可选分享标题带 streak（不送虚拟货币）。

## 7. P1-B · 一次性订阅消息（可选，约 3–5 人天 + 合规）

**仅在 P0 证明 DAU 有起色后再做**——要改架构与隐私。

| 项 | 说明 |
| --- | --- |
| 架构 | 微信云开发最小集：云函数发订阅消息；小程序 `wx.requestSubscribeMessage` + `wx.login` |
| 触发时机 | 用户**主动**在设置里开「明日提醒」；或快敲结束后**可选**勾选「明天同一时间提醒敲一下」 |
| 模板 | 类目库内「待办/活动结果」类，文案：**「今日敲击记录已保存，有空来解压 30 秒」**——不提宗教 |
| 发送窗口 | **17:00–20:00** 或「上次打开 + 24h」；**禁止 0–2 点**（QuestMobile 夜经济：深夜活跃但打扰成本高） |
| 隐私 | `PRIVACY.md` 增加：openid、订阅消息下发；用户可拒收 |
| 限制 | 工具类**无长期订阅**；每次提醒需用户再次订阅 |

## 10. 文案与审核备忘（可直接给提审用）

**推荐说法**

- 解压、轻互动、静心小玩具、敲击计数、数据仅存本机。

**避免说法**

- 祈福灵验、消灾、超度、开光、法事、直播仪式、互联网宗教信息。

**分享 / 订阅示例**

- 分享：`今日敲击 128 次 · 电子木鱼`  
- 订阅：`您设置的解压提醒：今天还没敲过，来放松 30 秒吧`（用户主动订阅后）

## 12. 建议你先拍板的 3 个问题
