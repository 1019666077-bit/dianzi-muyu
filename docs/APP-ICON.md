# 小程序头像（WeChat Mini Program Avatar）

产品：**天天敲木鱼涨功德**（短名：天天敲木鱼）

## 上传哪张

**请上传：`mp-weixin/assets/branding/app-icon-512.png`**

- 由 **`share-cover.webp` 裁切**（去掉底部「电子木鱼」字），背景换成与小程序一致的 `#0d0a06`。
- **不含木槌**，避免与鱼体叠在一起产生「穿模」感；与分享卡、游戏内木鱼造型一致。
- `app-icon-144.png` 为 512 缩小对照，一般不必单独上传。

备用：`mp-weixin/assets/branding/app-icon-512-layers.png`（仅 ground+body 分层合成，无字无槌）。

重新生成（本地）：

```bash
python tools/compose_app_icon.py
```

## 后台步骤

1. [微信公众平台](https://mp.weixin.qq.com/) → **设置** → **基本设置** / **基本信息**
2. **小程序头像** → 修改 → 选择 `app-icon-512.png`
3. 裁剪框内木鱼居中，留约 10% 边距（微信会再裁圆角）
4. 保存并等待审核

名称、简介在后台单独填写，**不要把简称写进图标**。

## 规格

| 项 | 要求 | 本仓库 |
|---|---|---|
| 格式 | PNG / JPG 等 | PNG |
| 边长 | 建议 144；可传更大 | 512 上传，144 对照 |
| 大小 | &lt; 2 MB | 约 280 KB |
| 内容 | 无违规、小图可辨 | 单木鱼，无槌、无汉字 |

设计说明：旧版 AI 立体图曾出现槌插入鱼体、shade 层重影；现版改为与线上一致的分享图裁切，保证与小程序内视觉同一套素材。
